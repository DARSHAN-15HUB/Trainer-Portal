## Trainer Portal

**Project Purpose:** To develop a web-based Trainer Portal that helps trainers manage student information efficiently.

**Features:**
- **Student Management:** Allows trainers to add, view, update, and delete student records.
- **User Authentication:** Provides secure registration, login, and logout for individual trainers.
- **Data Management:** Stores student details like name, roll number, marks, email, course, contact, and address using Django and SQLite.

**Tech Stack:** Python, Django, SQLite, HTML, CSS
